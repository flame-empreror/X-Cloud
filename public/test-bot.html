🔍 Telegram Bot Test Tool

Use this tool to test your bot token and channel connection before using TeleCloud

Step 1: Test Bot Token

💡 Get your bot token from @BotFather on Telegram. Format: numbers:letters

Step 2: Test Channel Connection

💡 For public channels: use @username (e.g., @mychannel)
💡 For private channels: use numeric ID (e.g., -1001234567890)
💡 Make sure your bot is added as administrator to the channel!

Step 3: Test Sending Message

💡 This will send a message to your channel. If it works, your bot can post to the channel.
